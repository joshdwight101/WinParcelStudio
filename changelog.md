# WinParcel Studio changelog

## 1.1.0

- Added optional Authenticode signing of staged PowerShell files using a PFX or P12 certificate.
- Added a signing review, checksum-verified signer installer, and optional RFC 3161 timestamp support.
- Added terminal signing options with a hidden password prompt.

## 1.0.0

- Added a GTK desktop app and native Ubuntu command-line tool for Intune Win32 packaging.
- Added source and output pickers, MSI property extraction, quiet modes, and clipboard commands.
- Added Microsoft release downloads and optional Wine execution with catalog support.
- Added an application icon, shortcuts, an offline user guide, and an About dialog.
